# WTWR (What to Wear?): Back End

WTWR is a full-stack web application that provides up-to-date weather information and dynamic clothing recommendations based on current local weather data.

The back-end project focuses on a robust server architecture built to handle databases, user authentication, security protocols, automated testing, and remote machine deployment.

To explore the live application or view the source code, check out the resources below:

## 💻 Running the Project Locally

To test the backend functionality locally alongside the frontend:

1. Clone this repository and the **Frontend GitHub Repository** linked above into neighboring directories.
2. Run `npm install` in both the frontend and backend project roots to install dependencies.
3. Start the backend server first using `npm run dev` (runs on `http://localhost:3001`).
4. Start the frontend server using `npm run start` (runs on `http://localhost:3000`).

## 🛠️ Technologies Used

- **Backend:** Node.js, Express.js, MongoDB, Mongoose, RESTful APIs
- **DevOps & Deployment:** Google Cloud Platform (GCP), Nginx, PM2, SSL/TLS certificates, Subdomain configuration
- **Frontend & Testing:** React, JavaScript, HTML5, CSS3, Postman

## 🚀 Future Enhancements

- **Local File Uploads:** Allow users to upload pictures of their own clothing from their local devices into specified wardrobe categories.
- **3D Model Integration:** Generate a visual combination of selected clothing on a customizable or 3D model image.
- **Social Sharing:** Enable users to upload and share images of their curated daily outfits directly to social media.
