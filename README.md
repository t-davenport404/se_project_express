# WTWR (What to Wear?): Back End

The back-end project is focused on creating a server for the WTWR application. Creating a deeper understanding of how to work with databases, set up security and testing, and deploy web applications on a remote machine. The eventual goal is to create a server with an API and user authorization.

## Technologies Used

- JavaScript
- MangoDB
- Express
- RESTful APIs
- Postman
